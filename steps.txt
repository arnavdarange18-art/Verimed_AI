Run these in Cursor's terminal:

1. Install NER dependencies:
pip install transformers torch
⚠️ This is a bigger install (~1-2GB with torch). Let it finish.
2. Test NER alone first:
python ner_utils.py
First run will download the model (~400MB, one-time). You should see entities extracted for each test claim, e.g.:
Claim: 'Garlic cures COVID-19'
  -> garlic  [...]  confidence=0.8x
  -> COVID-19  [Disease_disorder]  confidence=0.9x
3. Test the full pipeline with NER included:
python verify_v2.py
This now shows entities detected → search query used → verdict, so you can see exactly how NER sharpened the retrieval.

A note on the "BERT" requirement: I used d4data/biomedical-ner-all instead of raw dmis-lab/biobert-v1.1, because the base BioBERT checkpoint has no NER head — it needs fine-tuning on a labeled dataset before it can extract entities at all, which eats hours you don't have. The model I used is a BERT/biomedical-transformer architecture, already fine-tuned for exactly this task. When you present, you can honestly say "we use a BioBERT-based NER model" — it's true and it works live.
